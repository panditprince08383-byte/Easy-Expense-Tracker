# Easy Expense Tracker

## Project Overview
Easy Expense Tracker is a Python-based application
for managing daily expenses.

## Features
- Add new expenses
- View saved expenses
- Calculate total expenses
- Store expense records
- Manage daily spending

## Technology Used
- Python 3
- JSON
- File Handling

## How to Run
1. Install Python 3.
2. Download the project file.
3. Run the Python file.

## Project Objective
To make daily expense management easy
using basic Python programming.
